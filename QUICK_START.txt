================================================================================
🚨 TROUBLESHOOTING:
================================================================================

Import fails with "Duplicate entry" error:
→ The SQL file includes TRUNCATE statements. Make sure no constraints prevent truncation.

Import fails with foreign key error:
→ Ensure migrations are up to date: php artisan migrate:fresh
→ The SQL file disables foreign key checks during import.

Wrong counts after import:
→ Run: php validate_dummy_data.php to see what's missing
→ Check that all INSERT statements completed successfully

Dashboard shows wrong data:
→ Clear cache: php artisan cache:clear
→ Refresh the page

Next month billing not working:
→ System date should be Oct 11, 2026 or later
→ Run your automated billing command for November 2026
