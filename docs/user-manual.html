1. Introduction

1.1 System Overview

The Dormitory Management System is a comprehensive web-based application designed to streamline the management of dormitory operations. The system handles room assignments, tenant management, contract processing, invoice generation, payment tracking, utility billing, and deposit management.

Purpose

This system eliminates manual paperwork and provides real-time visibility into all aspects of dormitory operations, ensuring transparency, accountability, and efficient management.

1.2 User Roles

The system supports three distinct user roles, each with specific permissions and capabilities:

Role Description Key Responsibilities
Owner Full system administrator with complete access
  • Manage employees
  • Configure system settings
  • View financial reports
  • Manage all operations
Employee Staff member handling daily operations
  • Process payments
  • Record meter readings
  • Generate invoices
  • Manage laundry services
Tenant Resident with view-only access to personal information
  • View bills and invoices
  • Make online payments
  • Check deposit status
  • View contract details

1.3 Key Features

For Owners and Employees

  • Room Management: Track room status, capacity, rates, and amenities
  • Contract Management: Create and manage rental agreements with multiple tenants per room
  • Deposit System: Track security deposits with deduction capability for damages
  • Automated Invoicing: Generate monthly bills with electricity calculations
  • Payment Tracking: Record and monitor payments from multiple tenants
  • Meter Readings: Track electricity consumption for accurate billing
  • Laundry Services: Manage laundry orders and track revenue
  • Financial Reports: Generate comprehensive financial summaries
  • Audit Trail: Complete logging of all system activities

For Tenants

  • Online Bill Viewing: Access current and historical invoices
  • Payment Portal: Pay bills securely using PayMongo integration
  • Deposit Transparency: View deposit balance and all deductions
  • Contract Information: Access rental agreement details
  • Payment History: Track all payment transactions

2. Getting Started

2.1 System Requirements

The system is web-based and accessible from any device with:

  • Modern web browser (Chrome, Firefox, Safari, or Edge)
  • Internet connection
  • Minimum screen resolution of 1024x768 pixels (desktop recommended)

2.2 Accessing the System

1 Open your web browser and navigate to the system URL

Enter the web address provided by your system administrator.

2 Login Page

You will see the login page with fields for email and password.

3 Enter your credentials
  • Email: Your registered email address
  • Password: Your account password
4 Click "Login"

You will be redirected to your role-specific dashboard.

First Time Users

Owners and Employees: Register using the "Register" link on the login page.
Tenants: Your account will be created by staff. You will receive a password reset email to activate your account.

2.3 First Time Login

For Tenants

When your account is created, follow these steps:

1 Check your email

You will receive a password reset email with an activation link.

2 Click the activation link

This opens the password setup page.

3 Create your password

Enter a strong password (minimum 8 characters) and confirm it.

4 Login with your new password

Return to the login page and access your tenant portal.

Security Reminder

Never share your password with anyone. The system staff will never ask for your password. If you forget your password, use the "Forgot Password" link on the login page.

Dashboard Components

The room management module allows you to track and configure all dormitory rooms.

Viewing Rooms

  • Floor: Floor number
  • Capacity: Maximum number of tenants (1-4)
  • Monthly Rate: Base rent amount

The room is created and added to the system.

Editing Room Information

1 Click "Edit" on any room
2 Update the necessary fields
3 Click "Update"

Room Status Values

  • Vacant: Available for new tenants
  • Occupied: Currently rented
  • Maintenance: Under repair or renovation

3.4 Contract Management

Contracts link rooms with tenants and define rental terms. The system supports multiple tenants per contract (room sharing).

3.4.1 Creating Contracts

Follow these steps to create a new rental contract:

1 Navigate to Contracts → Create
2 Select a room

Choose from available vacant rooms. The room rate is automatically displayed.

3 Select tenants

Choose one or more tenants from the list of available tenants. The system shows available tenants who are not currently in an active contract.

Capacity Warning

The system will warn you if you select more tenants than the room capacity. You can proceed if necessary, but it's not recommended.

4 Set contract terms:
  • Start Date: When the contract begins
  • Due Day: Day of month when rent is due (1-28)
  • Deposit Required: Security deposit amount
5 Click "Create Contract"

The contract is created and the room status changes to "Occupied".

Per-Tenant Calculations

When multiple tenants share a room, the system automatically splits rent and utility bills equally among all tenants in the contract.

3.4.2 Deposit Management

The system tracks security deposits throughout the contract lifecycle. Deposits can be collected, deducted for damages, or refunded.

Viewing Deposit Information

1 Open any contract

Click on a contract number to view details.

2 Scroll to Deposit section

Located below the Invoices section on the right side.

3 Review deposit information:
  • Current Balance: Displayed prominently at the top
  • Transaction History: All collections and deductions
  • Staff Member: Who recorded each transaction
  • Reasons: Explanation for each deduction

3.4.3 Deposit Deductions

When property damage occurs, you can deduct repair costs from the security deposit. This provides transparency and accountability for both parties.

New Feature: Deposit Deduction System

Record damages and deduct costs directly from tenant deposits. All deductions are immediately visible to tenants with full reason details.

Recording a Deposit Deduction

1 Navigate to the contract

Open the contract where damage occurred.

2 Scroll to Deposit section

Find the deposit information on the right side.

3 Click "Deduct from deposit"

This expands the deduction form.

4 Fill in deduction details:
  • Amount: Cost of repair or replacement (cannot exceed current balance)
  • Date: When the damage occurred or was discovered
  • Reason: Detailed explanation of the damage and repair cost

Example Reasons

  • "Broken window in bedroom - glass replacement cost ₱2,500"
  • "Wall paint repair - multiple holes from picture hanging ₱800"
  • "Lost room key - lock replacement required ₱500"
  • "Damaged door handle - replacement and installation ₱350"
5 Click "Record deduction"

A confirmation dialog appears showing the amount and warning.

6 Confirm the deduction

The deduction is recorded and balance is updated immediately.

What Happens After Deduction

  • The deposit balance is reduced by the deduction amount
  • The transaction appears in the deposit history
  • All tenants in the contract can see the deduction and reason
  • An audit log entry is created with your name and timestamp
  • The new balance is displayed prominently

Important Notes

  • You cannot deduct more than the current deposit balance
  • Deductions are permanent and cannot be undone (contact support if needed)
  • Be specific in your reason to maintain transparency
  • Deductions apply to all tenants in the contract equally
  • Only active contracts allow new deductions

Tenant Visibility

Tenants can view all deposit deductions in their portal under the "Deposit" section. They see:

  • Current refundable balance
  • Date of each deduction
  • Amount deducted
  • Detailed reason for the deduction
  • Staff member who recorded it

Deactivating a Contract

When a tenant moves out or a contract ends:

1 Open the contract
2 Click "Make inactive"

This button appears at the top right of the contract page.

3 Confirm the action

A warning appears explaining that:

  • All unpaid invoices will be voided
  • The room will be marked as vacant
  • This action cannot be undone
4 Click "OK" to proceed

Deposit Refunds

After deactivating a contract, review the remaining deposit balance. Record any final deductions before processing the refund to the tenant.

3.5 Invoice Management

The system automatically generates monthly invoices for all active contracts based on meter readings and configured rates.

Generating Invoices

1 Navigate to Invoices
2 Click "Generate Invoices"
3 Select the billing month

Choose the month for which to generate invoices.

4 Review the preview

The system shows how many invoices will be created.

5 Click "Generate"

Invoices are created for all active contracts.

Prerequisites

Before generating invoices, ensure that meter readings have been recorded for the billing month. Without meter readings, electricity charges will be zero.

Viewing Invoice Details

1 Click on an invoice number
2 Review invoice information:
  • Invoice number and date
  • Room and contract details
  • Rent amount
  • Electricity consumption and charges
  • Previous balance (if any)
  • Credit balance applied
  • Total amount due
  • Per-tenant share
  • Payment status for each tenant

Invoice Statuses

Status Description
Pending Invoice issued but not yet due
Paid All tenants have paid their share
Partial Some but not all tenants have paid
Late Past due date but within grace period
Overdue Past grace period, action required
Void Cancelled (usually due to contract termination)

Record payments received from tenants through various payment methods.

Recording a Cash Payment

1 Open the invoice

Navigate to the invoice for which payment was received.

2 Locate "Record cash payment" panel

Found on the right side of the invoice page.

Choose which tenant made the payment.

4 Enter payment details:
  • Amount: Payment amount received
  • Method: Cash, GCash, Maya, Bank Transfer, etc.
  • Date: When payment was received

5 Click "Record Payment"

The payment is recorded and invoice status is updated.

Overpayment Handling

If a tenant pays more than their share, the excess is automatically applied as credit to their next invoice.

Viewing All Payments

1 Navigate to Payments

View a complete list of all payment transactions.

2 Filter and search

Use filters to find specific payments by date, tenant, or method.

6. Troubleshooting

6.1 Common Issues

Login Issues

Problem: Forgot Password

Solution:

  1. Click "Forgot Password" on the login page
  2. Enter your email address
  3. Check your email for the reset link
  4. Click the link and create a new password

Problem: Account Not Activated (Tenants)

Solution:

  1. Check your email for the activation link
  2. If you can't find it, check your spam folder
  3. If still not received, contact management to resend

Problem: Account Locked

Solution:

Contact management immediately. Only administrators can unlock accounts.

Payment Issues

Problem: Online Payment Failed

Solution:

  1. Check your internet connection
  2. Verify your payment method has sufficient funds
  3. Try a different payment method
  4. If problem persists, contact PayMongo support or pay via cash

Problem: Payment Not Reflected

Solution:

  1. Wait 5-10 minutes for the system to update
  2. Refresh your browser
  3. If still not reflected after 30 minutes, contact management with your transaction reference

Invoice Issues

Problem: Invoice Amount Seems Incorrect

Solution:

  1. Check the invoice breakdown for your share
  2. Verify the number of tenants in your contract
  3. Review the meter reading and consumption
  4. Check if there's a previous balance carried forward
  5. Contact management if you still believe there's an error

Deposit Issues

Problem: Don't Understand Deposit Deduction

Solution:

  1. Review the deduction reason in your deposit history
  2. Check the date when the deduction was made
  3. Contact management for clarification
  4. Request documentation of the damage (photos, repair receipts)

Problem: Dispute a Deduction

Solution:

  1. Document your concern in writing
  2. Contact management within 7 days of the deduction
  3. Provide any evidence supporting your claim
  4. Management will review and respond within 3 business days

Technical Issues

Problem: Page Not Loading

Solution:

  1. Check your internet connection
  2. Try refreshing the page (F5 or Ctrl+R)
  3. Clear your browser cache and cookies
  4. Try a different browser
  5. Contact support if problem persists

Problem: Cannot Upload Files

Solution:

  1. Check file size (maximum 10MB)
  2. Verify file format is supported
  3. Try a different browser
  4. Contact support if problem persists
